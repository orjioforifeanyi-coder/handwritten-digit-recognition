Handwritten Digit Recognition

Project Overview

This project focuses on building a Handwritten Digit Recognition system using Deep Learning and Convolutional Neural Networks (CNN).

The model is designed to recognize handwritten numerical digits (0–9) from image data.

Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Jupyter Notebook
- Convolutional Neural Networks (CNN)

Project Workflow

1. Load the handwritten digit dataset.
2. Prepare and preprocess the image data.
3. Build a Convolutional Neural Network.
4. Train the model using TensorFlow/Keras.
5. Evaluate the model's predictions.
6. Visualize actual and predicted digits.

Project Files

- "handwritten_digit_recognition.ipynb" — Main notebook containing the project code, model training, evaluation, and predictions.
- "handwritten_digit_model.keras" — Saved trained model, if included in this repository.
